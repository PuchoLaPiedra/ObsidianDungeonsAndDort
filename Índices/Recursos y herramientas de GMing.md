Combates normales
	Escaramuza
	Emboscada ( defensa o ataque )
	Hordas
	Equipo de Elite
	Boss

Escenarios especiales
	Golpe ( planificado )
	Eventos deportivos / competitivos

	Rescate, robo, secuestro

	Recompensa ( item o plata )
